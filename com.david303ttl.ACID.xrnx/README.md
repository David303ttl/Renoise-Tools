# ACID.xrnx

ACID 0.1 — read-only development scaffold. This package identity and
qualified folder layout are integrated independently of the unfinished
sequencer implementation in PR #9.

Open **Tools > ACID...** or the Pattern Editor context menu. Inspect the
selected pattern or change the draft timing length. No notes or phrases
are generated by this baseline tool.

Modules follow the standalone XRNX layout:
- `main.lua`, `manifest.xml`, `gui.lua` in package root
- `model/sequencer.lua` for the draft pitch/time memory
- `renoise/selection_context.lua` for read-only selection inspection

Run `lua tests/acid/acid_sequencer_spec.lua` from the repository root,
or `pwsh -NoProfile -File ./scripts/run_tests.ps1 -Tool ACID`.

Full pitch/time compiler, pattrns phrase generation, sample articulation,
and the editable UI remain in draft PR #9. Do not change version 0.1.
